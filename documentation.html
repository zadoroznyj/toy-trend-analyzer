Purpose and access

The Tool is a private toy-market research application. Its workflow consists of YouTube Data API collection, local SQLite storage, local analysis/report generation, and a Telegram bot limited by a configured chat allowlist. It is not a public user analytics platform. No Google OAuth user authorization flow is implemented; API access uses an API key.

Architecture

The collector uses YouTube API resources and writes metadata/statistics into SQLite. Analysis reads local records and writes locally derived classifications and reports. The Telegram bot polls updates, checks an allowlist, reads reports, and sends authorized responses.

API methods observed in the project

  • search.list — discovery of videos/channels, constrained by a project-side daily cap.
  • playlistItems.list — enumerate a channel’s uploads playlist during collection.
  • videos.list — retrieve video metadata/statistics in batches.
  • channels.list — retrieve channel metadata/statistics where requested.

Calls are subject to the project’s configured API key, YouTube quota rules, and policy restrictions. The local daily search cap is a project guardrail, not a Google quota grant.

Current implementation (inspected in source; raw experiment run on 2026-11-24)

  • Discovery and channel video collection are separate workflows. Video Discovery now rotates weighted regional buckets: LT, PL, DE, US, RU, UA, GB, LV, EE, and worldwide search without a regionCode. Configured weights are experimental query-allocation choices and are not evidence about the location of creators, viewers, or buyers.
  • Video Discovery rotates `order=relevance`, `viewCount`, and `date`, and publication windows of 3, 7, 14, and 30 days. Search attribution stores the chosen order and window. The same SQLite-backed atomic `search.list` reservation is shared between video and channel Discovery.
  • The 2026-11-24 blind experiment used generic multilingual phrases; date-seasonal phrases were configured but their coverage was not established. The experiment used with search.list(type=video), then batched videos.list statistics. It saved raw outputs separately and did not calculate product, trend, or commercial scores. One initial DNS failure consumed a local reservation and was not retried.
  • Collected metadata and timestamped public statistics are stored in SQLite.
  • Local product-classification and score algorithms remain in source but a fail-closed configuration gate defaults off and requires an owner-recorded approval status/reference. This local switch cannot validate that Google has actually granted approval.
  • When the gate is off, product classification returns unresolved, trend calculation/report commands stop, and Telegram `/trends` and `/report` do not distribute stored derived results.
  • The 30-day cleanup removes raw API records, unapproved derived tables, recognized report outputs/caches, raw experiment exports whose manifest expiry has passed, and recognized SQLite backup copies. Cleanup is not scheduled by this change; all other copies outside those named paths require owner review.
  • A local deletion-request CLI records requests and requires explicit operator confirmation before deleting local video/channel data, report artifacts, and matching project SQLite backup records. It does not provide a public form or delete YouTube source content.
  • The Telegram bot is restricted by its configured chat allowlist. `/report` acknowledges promptly and builds/sends the PDF on a single background worker; PDF files are written to a temporary path and atomically replaced. Concurrent requests share one active generation.
  • PDF text uses a Unicode font and replaces unsupported pictographs with `[icon]`. The renderer embeds only local PNG/JPEG fixtures under `reports/synthetic_assets/` whose filenames start `synthetic_`; remote URLs and ordinary YouTube thumbnail URLs are not fetched or embedded.
  • Source attribution is included in generated Markdown/PDF and the `/youtube` response. This is not a YouTube endorsement and does not replace full policy review.
